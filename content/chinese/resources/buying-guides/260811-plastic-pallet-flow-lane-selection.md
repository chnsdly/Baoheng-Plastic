用于重力式托盘流道时，塑料托盘应按**底面接触结构和预定运行方向**选择，而不是只看外形尺寸或通用承载数值。比较型号前，应向流道设计方提供底视图、装载后托盘的尺寸和质量范围，以及实际温度和流道资料。

这与普通横梁货架或动力输送线是不同的采购任务。某托盘即使适用于叉车，底部的脚墩、滑道或柔性结构也可能无法按流道要求接触滚筒。流道方负责流道设计；托盘供应商负责说明实际型号；现场团队负责确认完整单元载荷和操作方法。

## 先取得底视图和运行箭头

询问供应商某型号是否“适用于流利架”之前，先取得当前托盘流道设计表或同等技术问卷。Interroll 的托盘流道设计资料要求提供底板视图、流动方向、托盘尺寸、最小和最大载荷、货物尺寸、是否固定、温湿度、流道结构、滚筒或轨道资料以及止挡或制动装置。这些字段说明：标称托盘尺寸并不足以作出选择。[Interroll 托盘流道设计资料](https://www.interroll.com/fileadmin/user_upload/AMERICAS/Application_Data_Sheets/Interroll-Pallet-Flow-Form.pdf) 仅适用于其系统；实际项目须使用流道方的最新文件。

应一并提交以下信息：

| 信息 | 为什么会影响选择 |
| --- | --- |
| 底视图或样品 | 滑道、脚墩、支脚、开孔和筋的位置决定托盘怎样接触流道。 |
| 运行方向 | 同一托盘旋转后，可能以不同接触结构进入滚筒或轨道。 |
| 完整载荷范围 | 最小和最大质量、占地、高度和固定方式会影响启动、速度、停止和接触。 |
| 流道资料 | 滚筒或轨道类型、中心距、坡度、长度、止挡、制动、温湿度属于流道设计方的范围。 |
| 托盘型号证据 | 图纸、版本、材料说明和适用边界用于识别供应商实际报价的型号。 |

ISO 6780:2003 涵盖新平托盘的主要尺寸、公差及开孔、间隙、倒角和翼缘等搬运特征。它有助于准确描述托盘接口，但并不批准某一托盘用于特定流道、完整载荷或操作条件。[ISO 6780:2003](https://www.iso.org/standard/30524.html) 目前仍被 ISO 列为有效标准，且于 2026 年确认。

## 按接触问题选型，不按通用标签选型

应根据证据判断需要评估的接触问题。连续滑道与离散脚墩或支脚会向滚筒或轨道呈现不同支撑形式；柔性底部在流道内停放一段时间后也可能贴合滚筒。这些描述本身既不证明合格也不证明不合格，结果取决于实际流道、方向、载荷和环境。

Mallard Manufacturing 记录了一个轻型、错位脚墩塑料托盘在分体滚筒流道中的测试。其案例指出，有限接触会改变流动行为，装载后的托盘在流道中静置后可能贴合滚筒。这是设备方的案例，并不是适用于所有托盘或流道的规则；但它说明为什么在确认流道设计前需要有代表性的满载样品。[Mallard 的托盘流道测试案例](https://mallardmfg.com/how-to-build-a-pallet-flow-lane-for-plastic-pod-pallets-mallard-how-to/)可供参考。

可采用以下简短路径：

1. 取得流道方最新输入表，并确定允许的托盘方向。
2. 将实际托盘底视图与拟用轨道、导轨或滚筒接触结构比较。
3. 将完整载荷范围和环境条件与流道资料并列；不能以空托盘演示代替决定。
4. 如流道方要求，在采购批准或常规使用前安排代表性的满载试验。
5. 记录试验覆盖的型号、图纸版本、载荷、方向、流道版本和决定责任人。

## 在 RFQ 中单列流道接口栏

不要把流道要求藏在后期试验说明中。应在询价文件中单列一栏，使各供应商回复可比较。

| RFQ 字段 | 应要求的内容 |
| --- | --- |
| 流道依据 | 流道方、系统图纸或资料版本、流动方向和已声明的托盘接口要求。 |
| 托盘底面几何 | 底视图、滑道或支脚布置、开孔、接触面和型号版本。 |
| 完整单元载荷 | 质量范围、占地、高度、悬挑、包装、固定方式和相关静置条件。 |
| 环境 | 现场或流道方规定的温度、湿度及冷库或卫生条件。 |
| 证据边界 | 哪些事实由托盘供应商提供，哪些须由流道方或现场评估。 |
| 验收 | 所需代表性试验、记录、验收责任人及触发复核的变更条件。 |

这是一种有限的采购方法，不是计算公式或保证。它避免把供应商的尺寸或一般承载说明误认为已覆盖流道的底面接触、控制部件、速度、止挡或满载运行路线。

## 试验必须覆盖真实运行组合

在常规使用前，负责的流道方和现场团队应依据当前流道文件，确认实际托盘型号在允许方向下与预定完整单元载荷的组合。必要时应包括进入、运行、止挡或分离装置、相关静置时间、出库和下一转运点，并记录接触、启动、速度、停止、间隙、载荷状态和决定。

托盘型号或底面结构、载荷、缠绕方式、方向、流道硬件、坡度、环境、操作方法或控制系统改变时，应重新核查。某一托盘和某一完整载荷的通过结果，不能自动批准其他组合。

本指南提供了更早且可执行的选择控制：在报价或样品被视为相关之前，用底视图和流道资料比较塑料托盘。它不能代替流道方设计、现场安全评估、设备说明或当地要求。
