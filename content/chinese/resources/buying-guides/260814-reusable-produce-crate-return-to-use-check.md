空周转箱看起来干净，并不等于可以马上重新接触食品。它回到果蔬循环使用系统前，应分别确认四件事：箱体是否完好；是否按本场所批准的程序清洗，必要时消毒；需要的验证和放行记录是否完成；放行后是否得到保护、避免再次污染。任何一项不清楚，都不要把它放入清洁箱池，应按本场所食品安全程序暂存和处理。

本工具适用于接触完整新鲜果蔬的可重复使用塑料周转箱。它不规定通用的清洗剂、接触时间、微生物限值或法律要求；这些要由产品、工艺、当地法规、客户要求、化学品说明和食品安全计划决定。

## 四道放行关口

| 关口 | 只有在以下情况才可回到清洁箱池 | 出现以下情况应隔离并升级处理 |
| --- | --- | --- |
| 箱体状况 | 箱体完整、可清洁，没有裂纹、尖锐破损、嵌入污物或难以清洁的缺陷。 | 发现破损、残留物、异味、虫害痕迹或不可有效清洁的表面。 |
| 处理程序 | 已知并完成适用的清洗程序，以及本场所要求的消毒程序。 | 清洗历史、既往用途、化学品程序或冲洗要求不明确。 |
| 过程控制 | 食品安全计划要求的检查、记录和放行决定均已完成。 | 缺少浓度检查、检验记录或指定放行人员。 |
| 清洁状态保护 | 放行后存放和搬运能控制灰尘、害虫、积水和其他污染。 | 露天或失控区域存放、发生污染事件，或与脏箱混放。 |

美国 FDA 的果蔬指南提出应定期检查容器；受损的容器表面可能藏匿微生物并损伤果蔬，不应继续使用。该指南还建议在运输新鲜果蔬前清洗托盘、容器或箱子，并保护已清洗或新包装容器免受害虫、灰尘和冷凝水污染。[FDA 指南](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/guidance-industry-guide-minimize-microbial-food-safety-hazards-fresh-fruits-and-vegetables)

## 在回收点作出决定

1. **脏箱与清洁箱分开。** 使用过、露天存放、受损或状态不明的周转箱不能与已放行箱混放；为回收区设置清楚状态和通往检查/清洗区的路线。
2. **放行前检查。** 查看角部、筋条、把手、排水孔和堆叠部位是否有破损、夹藏污物或影响清洗的缺陷。不能仅擦拭后放行明显有问题的箱子。
3. **使用批准程序，不套用通用配方。** “已消毒”必须对应既定程序。FDA 区分肉眼清洁与清洗后的消毒；消毒效果必须适合实际表面和工艺。请遵循本场所计划及化学品/设备说明，不要照搬本文的浓度或时间。
4. **保护已清洁状态。** 避免让放行箱接触土壤、废弃物、害虫、积水和顶棚冷凝水。清洗后又露天存放的箱子，不应默认仍然清洁，应重新进入本场所的判断流程。
5. **放行或隔离。** 仅当状况、程序、控制和存放四项均确认无误时放行；否则贴标或隔离，并交由指定质量或食品安全负责人处理。

## 将检查表写入周转箱循环规范

采购时向供应商索取具体产品信息，但食品安全放行决定仍应由使用方负责。

| 需要确认 | 原因 |
| --- | --- |
| 箱型、材料声明、尺寸和承载/堆叠限制 | 明确具体产品及其预期使用条件。 |
| 易清洁特性与制造商保养说明 | 帮助评估本场所批准程序是否适用；这不是消毒验证。 |
| 损坏拒收标准和更换流程 | 避免裂纹或不可清洁的箱子回流。 |
| 脏箱接收、清洗、放行、受保护存放的布局 | 让状态分隔可见，而不是依赖记忆。 |
| 记录、责任人和变更触发条件 | 将放行证据保留在负责的食品安全体系中。更换作物、化学品、清洗方法、存储条件、客户要求或发生污染事件后，应重新评估。 |

## 证据边界

FDA 指南是面向美国新鲜果蔬的指导，支持上述实用关口，但不认证某一款塑料箱，也不批准某个工厂的卫生计划，不能取代适用的当地法规或客户要求。英国 HSE 还指出，在食品饮料行业，容器（包括周转箱）的堆叠和拆垛是需要在实际工作环境中评估的人工搬运任务。[HSE 指南](https://www.hse.gov.uk/food/safety-hazards/handling.htm)

请用本资源明确周转箱重返清洁果蔬循环前必须确认的事项。实际清洗方法、化学品相容性、验证记录、存放控制、人工搬运和当地责任，应由质量、食品安全和运营负责人确认。
