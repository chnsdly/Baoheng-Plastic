塑料托盘不能只因尺寸常见或能用于普通货架，就被视为适用于穿梭车系统。应根据**具体穿梭车型号、该型号搬运托盘的方向、底部接触接口和完整单元载荷**来选择。这样，买方能在询价或试验前形成可执行的选型资料。

这是设备接口选型，而不只是托盘尺寸选择。某只托盘可能适用于叉车、地面堆放或选择性货架，却不一定是穿梭车巷道的正确载体。设备方决定其允许的托盘范围；托盘供应商说明实际型号；现场团队确认带载组合。

## 先确认穿梭车的搬运方向

不要从目录中的托盘尺寸开始，而应从已安装或计划安装的穿梭车系统文件开始。

例如，Mecalux 介绍其自动 Pallet Shuttle 系统有三种适配常见托盘尺寸的型号。在该系统中，托盘从 1,200 mm 一侧被搬运，深度对应 800 mm、1,000 mm 或 1,200 mm。此信息只说明该系统的特定接口输入，并非所有穿梭车系统的通用规则。有关这些配置，请参见 [Mecalux 自动 Pallet Shuttle 说明](https://www.mecalux.com/warehouse-automation/automated-pallet-shuttle)。

向设备负责人索取当前图纸或已批准的数据，并确认：

| 接口输入 | 为什么会改变托盘选择 |
| --- | --- |
| 确切的穿梭车和货架型号 | 不同系统可能有不同的允许尺寸、支撑点、传感器和入库要求。 |
| 规定的搬运方向 | 先进入设备的一侧决定了机器面对的托盘尺寸。 |
| 允许的总长、总宽、总高和质量 | 必须符合规定范围的是完整单元载荷，而不是空托盘。 |
| 底部接触与举升点 | 纵梁、底脚、底板和变形会改变设备接收与承载货物的方式。 |
| 单元载荷底面与悬垂 | 纸箱、袋装物、托盘、缠绕膜和护角会改变间隙与稳定性。 |

ISO 6780:2003 涵盖托盘主要尺寸和公差，并包括开口、间隙、倒角和翼边等与搬运有关的特征。ISO 在 2026 年确认后，该标准仍有效。它有助于准确描述托盘接口，但不批准某只托盘用于特定穿梭车、货架、载荷或运行条件。参见 [ISO 6780:2003](https://www.iso.org/standard/30524.html)。

## 判断是直接使用托盘，还是使用母托盘

不规则载体不应被假定能直接通过穿梭车巷道。Mecalux 指出，不规则托盘、半托盘或未托盘化货物必须放在与其穿梭车和货架兼容的标准托盘上；该标准托盘作为母托盘。这带来一个明确的选型分叉：

- **直接兼容托盘：** 选择实际尺寸和底部接口符合设备负责人规定范围的托盘。
- **母托盘方案：** 将不规则载体或货物置于已批准的标准载体上，并确定两者之间的接触、固定、货高和转移方法。

两种路径都不等于自动获准。母托盘增加了一个支撑面和一个接口，仍需由负责的现场团队和设备方评估。

## 在 RFQ 中写明接口，不要到试验时才补充

在托盘 RFQ 中单列设备接口信息。不要使用“兼容穿梭车”或“适合自动仓储”之类的笼统表述。

| RFQ 字段 | 应写明的内容 |
| --- | --- |
| 设备依据 | 确切的穿梭车、货架、输送交接点，以及设备负责人提供的图纸或数据版本 |
| 运行方向 | 哪一侧托盘先进入，以及是否允许旋转方向 |
| 托盘几何 | 外形尺寸、高度、叉孔、纵梁或底脚布局、底部接触区域，以及设备方给出的允许变形限值（如有） |
| 完整载荷 | 最大质量、底面、高度、可获得时的重心条件、悬垂、缠绕和垫衬 |
| 所需证据 | 当前型号图纸、声明的使用限制、样品身份，以及供应商确认其证据覆盖哪些要求字段 |
| 验收负责人 | 有权批准实际设备、货架、控制、带载样品和操作方法的人员或团队 |

该信息块可避免一种常见比较错误：供应商可以确认托盘型号尺寸，却不应声称买方的实际穿梭车巷道、货架轨道、控制系统或带载单元已获批准。

## 对真实带载路径进行试验

常规使用前，应由现场在计划托盘型号和正常完整载荷下进行受控试验。试验应采用约定方向，并覆盖入口交接、穿梭车运行、适用时的存储或取货，以及下一交接点。记录托盘型号与版本、带载尺寸和质量、货载状态、方向、设备数据版本、观察到的接触或间隙问题以及决策负责人。

当托盘设计、货载底面、缠绕方式、货架巷道、穿梭车型号、控制、允许设置或转移设备发生变化时，应停止并重新核对。一次干净的空载演示无法证明所有带载条件。

## 把选型与设备批准分开

本指南为现有输送线和货架检查增加了一个更早的采购决策：在订购样品前，先按穿梭车已声明的接口选择载体。它不构成设备批准、货架承载能力、自动化安全放行或通用托盘尺寸结论。

采购或常规运行前，设备负责人和现场责任团队必须确认当前文件、实际托盘型号、完整载荷、穿梭车和货架配置、允许操作方法、控制系统及当地要求。托盘供应商只应确认其能够证实的型号相关信息。
