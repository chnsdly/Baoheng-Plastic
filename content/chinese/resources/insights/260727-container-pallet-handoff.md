塑料托盘测试报告可以是有用证据，但它不能批准一整柜货物。报告可能说明托盘型号、载荷条件和支撑条件；它通常不会说明谁设计了集装箱内的排布、核实了实际成品载荷尺寸、选择了固定方式，或在关门前验收了货物。

实用做法很简单：把已确认的托盘数据交给负责装箱和货物固定的人，再取得针对该路线的集装箱装载确认。两项确认要分开保存。

[IMO/ILO/UNECE CTU Code](https://unece.org/transport/intermodal-transport/imoilounece-code-practice-packing-cargo-transport-units-ctu-code) 是关于货物运输单元装载的非强制性全球操作指南。它覆盖多式联运链条，以及装箱、固定、接收和拆箱的人员。它可以帮助理解交接边界，但不能代替适用法律、承运人要求或现场程序。

## 不要把托盘额定数据当成集装箱批准

先问供应商文件实际覆盖什么。托盘额定数据可能只适用于指定载荷、支撑方式、温度、搬运方式或测试方法。集装箱方案还需要回答：

- 缠膜或打包后的单元货物实际长、宽、高和总质量是多少？
- 在该 CTU 中，托盘朝向、间隙、挡块和固定方式是什么？
- 质量分布是否符合该 CTU、运输路线和承运人限制？
- 关门前谁检查，目的地谁接收？

这些问题不会降低托盘的重要性。它们只是避免把“托盘选得对”误认为“整套运输安排已安全”。

## 在装载方案定稿前建立交接记录

使用一份简短、基于事实的交接记录。它不应是泛泛的证书，也不应承诺每票货都会表现相同。

| 交给装箱方的信息 | 与装载方案一并保留的信息 |
| --- | --- |
| 确切托盘型号、尺寸、面板和底部结构 | CTU 类型、路线、承运人限制和装载图 |
| 缠膜或打带后的实际单元货物尺寸 | 拟采用的朝向、间距、挡固、支撑或其他固定方式 |
| 总质量和已知的集中受力点 | 质量分布及特殊搬运限制 |
| 供应商数据的适用条件和排除项 | 装箱方的检查、批准和升级责任人 |
| 需要确认的产品、温度、叉车入口和搬运事实 | 路线需要时，实际试装的照片或测量记录 |

供应商通常可以说明报价托盘及其规定条件。装箱方或控制装载方案的一方需要判断真实单元货物和固定安排是否适合该集装箱运输。采购方应明确责任人，而不是让决定停留在报价单和装卸月台之间。

## 检查实际单元货物，而不仅是名义托盘

用于集装箱时，1200 x 1000 mm 的托盘并不必然等于 1200 x 1000 mm 的已装载单元。纸箱鼓包、护角、缠绕膜、标签、打带和摆放偏差都可能改变可用宽度和接触点。应在货物准备完成后测量正常载荷。

当货物采用紧密排列时尤其如此。UNECE 的 CTU 材料说明，紧密装载可帮助利用空间并减少货物移动，但前提是货物能够承受相互接触，并且采用适当的固定措施。如果紧密排列会压坏纸箱、把力传到载荷薄弱处，或使开门端存在危险，就不要强行采用该方案。

现有的[集装箱装载托盘尺寸指南](/zh/resources/insights/2625-plastic-pallet-size-container-loading-guide/)帮助团队按纸箱和目的地搬运条件选择尺寸。本页解决的是下一步：由谁确认已完成的单元货物可以按实际 CTU 路线装载和固定。

## 分清三类责任

当某一方被要求批准超出其证据范围的事项时，误解就会出现。

**托盘供应商。** 确认具体型号、提供的技术数据和已说明的使用条件，并指出哪些情况需要样品或针对产品的测试。

**装箱方或物流责任人。** 规划 CTU 装载和固定方式，确认实际尺寸、质量、分布、接触面、路线限制和检查节点。

**采购方、客户或收货现场。** 确认商业与收货条件，包括接受的托盘尺寸、卸货方式、回收所有权、客户规则和产品限制。

同一家公司可以承担多个角色，但每项决定仍应有责任人和相应证据。

## 出口路线变化时重新交接

出现实质变化时应重新评审，例如纸箱变更、SKU 更重、缠绕方式改变、托盘型号更换、集装箱类型不同、目的地收货方变化或承运人要求更新。之前的运输可以为下一票提供参考，但不能自动批准已改变的货物。

如果眼前的问题是纸箱在运输中滑动、倾斜或摩擦，请先阅读[运输中载荷偏移预防指南](/zh/resources/insights/2628-plastic-pallet-load-shift-prevention-transport/)。它解释托盘、单元货物和运输控制如何共同作用。如需为大批量采购确认样品，请用[批量订购前托盘载荷测试指南](/zh/resources/insights/2616-plastic-pallet-load-test-before-bulk-order/)分别记录托盘条件与 CTU 方案。

## 一个实用的放行问题

在放行集装箱前，请问：

> 我们是否既有托盘在规定条件下的证据，也有针对该单元货物、该 CTU 和该路线的独立责任人批准？

若任一答案不明确，应暂停批量放行，并补齐尺寸、装载方案、产品信息或责任评审。CTU Code 是指南，不是普遍的法律批准；托盘供应商不能仅凭托盘规格认证客户的完整集装箱装箱作业。

对于实际出货，请由负责物流或合规的人员确认适用法律和承运人要求。批量使用前，应以实际货物、集装箱和设备验证选定的托盘、单元货物和搬运方式。
