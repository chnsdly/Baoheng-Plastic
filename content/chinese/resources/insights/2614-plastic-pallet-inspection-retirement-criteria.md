当塑料托盘出现裂纹、变形、污染，或搬运表现与以往不同时，第一步不是判断能否把它转到较轻的工况，而是**标识、隔离并停止不确定的使用，直到针对这块托盘及其实际用途完成评估**。

这一边界很重要。贴上“仅限地面使用”的标签，并不能证明受损的川字脚、面板、支脚、焊接部位或加强结构仍能承载任何重量。通用文章也无法为未知型号设定剩余安全载荷或授权维修。

英国健康与安全执行局的 [PM15《托盘安全》指南（第四版）](https://www.hse.gov.uk/pubns/pm15.htm)适用于多种材料制成的通用平托盘。该指南要求标记、隔离受损托盘，并将其退出使用后维修或处置；同时建议托盘每次使用时都应检查。这里把它作为有用的英国操作指导，而不是全球法律要求或具体型号的载荷批准。

## 使用三种状态，不预设“降级使用”

现场筛查采用三个清楚的状态更容易管理：

1. **在用：** 已确认型号，并符合现场针对该型号和指定用途批准的标准。仅有表面磨损不能单独决定通过。
2. **隔离：** 损伤、暴露、身份缺失、作业表现变化或证据不确定，需要有能力的人员评估。保持卸载，并与可用托盘物理分开。
3. **退出：** 按托盘所有者或现场批准的维修、退回、回收或处置流程处理。不要自行维修，也不要因为“看起来还结实”就换到另一种用途。

把托盘转到其他用途，应视为一次新的适用性决定。再次投入使用前，需要确认具体型号、当前状态、载荷、支撑、设备、环境和批准责任人。

## 买方可直接使用的现场检查记录

可以按单块托盘、采购批次或重复缺陷模式建立记录。即使最终判断需要供应商、托盘池所有者、货架专业人员、设备供应商或其他有能力的人员完成，这份记录仍然有用。

| 记录项 | 需要记录的内容 |
| --- | --- |
| 身份 | 托盘型号、图纸或规格版本、所有者标记、采购批次或生产批次、模压日期码、可用的唯一编号 |
| 观察 | 具体缺陷、位置、现场测得的长度或面积，以及空载放置时是否平稳 |
| 事件或暴露 | 叉车撞击、跌落、货架接触、疑似超载、热、冷、紫外线、化学品泄漏、未知污染，或没有已知事件 |
| 单元载荷 | 货物及包装、实际和最大重量、底面尺寸、载荷分布、悬边和固定方式 |
| 支撑与存储 | 地面、堆码或货架；横梁跨度和方向、支撑条、停留时间及堆码方式 |
| 搬运接口 | 叉车或托盘车、货叉几何与进叉方向、输送线、自动仓储系统、缠绕机、登车桥或其他接触点 |
| 当前控制 | 隔离标识、隔离位置、日期时间、负责人，以及是否已卸载 |
| 证据 | 整体、缺陷、型号标记、底面及支撑点的清晰照片，并保留相关事故记录 |

不要在这类作业记录中写入客户联系人信息或无关个人资料。它的目的只是保存技术判断所需的现场条件。

## 记录状态前检查什么

PM15 针对塑料托盘列出的检查示例包括裂纹或其他机械损伤、冷热或化学损伤、面板或底部缺陷、支撑件磨损或永久变形、空腔残留物、紫外线相关老化以及永久变形。应结合实际结构使用这些提示，而不要把它们改写成适用于所有型号的统一尺寸阈值。

### 面板与载荷路径

检查裂纹、开裂、穿孔、尖锐边缘、局部压溃、面板缺失、永久下挠，或影响货物的表面变化。记录缺陷是否跨越加强筋、焊接点、连接处、边缘或已知支撑区域。不要只根据裂纹大小推断剩余承载能力。

### 川字脚、支脚与底部

检查断裂或扭曲的底脚、磨损的进叉边、接触点缺失、平面放置时晃动，以及底部与面板连接处的损伤。支撑几何发生变化，会以不同方式影响地面、堆码、输送线和货架使用。

### 加强结构与货架使用

记录钢管外露或松动、加强件端部周围裂纹、锈迹、异响或异常挠曲。托盘能在地面使用，并不代表可以重新上货架。货架跨度、方向、支撑方式、载荷分布、温度、停留时间和具体托盘规格都会影响判断。

### 污染与环境

识别未知液体、化学品气味、嵌入残留、易藏污的破损表面、受热、低温撞击、日晒，或超出该型号已确认边界的清洗过程。仅凭结构外观无法解决卫生或化学兼容性问题。

### 设备接触

检查货叉、托盘车小轮、输送线、传感器、导轨或缠绕机是否接触受损区域。同一位置反复出现缺陷，可能提示接口或操作问题，但这种模式不能证明托盘可以继续使用。

## 针对具体型号评估时要问的问题

发送检查记录时，可附上以下简短问题：

- 能否确认托盘身份和原始规格？
- 损伤是否涉及承载、支撑、进叉、加强或卫生关键区域？
- 针对这个型号和用途，需要什么检查或测试？
- 是否有经过授权的维修方法，谁可以执行？
- 如果建议其他用途，什么书面证据和验收标准支持这一用途？
- 用什么标记和记录，防止托盘回到未批准的场景？
- 是否需要检查同一批次、线路或事件中的其他托盘？

如果所有者标记显示托盘属于托盘池，应遵循托盘池所有者的退回和维修流程。PM15 明确建议需要维修的池用托盘首先退回所有者或其授权代表。

## 把检查结果转成更好的更换规格

检查记录不应只用于关闭缺陷工单，还应改善下一次采购。汇总以下信息：

- 失效型号或当前规格；
- 实际载荷及其分布；
- 叉车、托盘车、输送线、货架和自动化接口；
- 温度、清洗、潮湿、紫外线和化学暴露；
- 缺陷位置和重复频率；
- 与损伤相关的作业事件；
- 所需标识、加强、材料路线和检查控制；
- 数量、目的地及验收前所需证据。

这些事实有助于区分规格不匹配、撞击、误用、环境暴露与偶发事件，也能让不同供应方案在相同工况下比较。

如买方提供产品类型、尺寸、数量、用途、承重要求、搬运设备、货架条件和目的地，宝恒可协助筛选替换用塑料托盘。材料、加强、定制、价格和交期仍需按具体型号和订单确认。当前公开信息不包含认证、第三方检测报告或通用的受损托盘维修批准。

## 应始终保留的判断边界

检查可以发现问题，并保存评估需要的事实；仅凭外观不能确定受损托盘的安全载荷。当身份、损伤影响或用途适配性存在不确定时，先隔离；只有责任方批准了这一具体状态和用途后，才重新投入使用。
