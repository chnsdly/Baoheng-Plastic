# Baoheng greenfield prototype v1

This directory is an isolated, English-only review prototype for the approved five-page redesign.

- It is outside Hugo's `content`, `layouts`, `assets`, and `static` inputs.
- It does not change or publish any production URL, metadata, form handler, or content file.
- Product and application images are referenced from the existing `static/images` library without copying or editing them.
- Every form is preview-only. JavaScript prevents submission and no request is sent to `/api/lead`.
- Working copy must not be treated as a verified company, manufacturing, certification, load, MOQ, lead-time, warranty, or customer claim.

Review pages:

1. `index.html`
2. `products.html`
3. `plastic-pallets.html`
4. `product-3-runner-1210.html`
5. `application-warehousing.html`

Rollback: remove this directory. No existing website file needs to be restored.
